# animal research projects

為《戰艦世界》玩家打造的 Windows 繁體中文工具，整合亞服戰績查詢、目前戰局資訊、RP 回放與影片匯出，以及艦艇資料與配裝分析。

**目前正式版：V1.3.1** · [查看版本說明](https://github.com/Hunter0527/wows-helper-releases/releases/tag/v1.3.1)

## 下載

- [下載 Windows 安裝版](https://github.com/Hunter0527/wows-helper-releases/releases/download/v1.3.1/animal-research-projects-v1.3.1-Windows-x64-Setup.exe)

## V1.3.1 更新重點

- **結算畫面重新排版**：依原遊戲參考整理個人成績、隊伍成績、詳細報告、銀幣與經驗四頁，加入艦影、圖示、勳章與緞帶，並改善戰鬥時間與統計顯示。
- **近期與單艦戰績同步**：期間依本機已累積的歷史決定上限，單艦戰績跟隨所選區間，也可切回生涯資料。
- **戰局名單隨視窗調整**：縮小視窗或放大介面時，完整呈現雙方各 12 人；最大化後名單會使用可用高度，文字與欄位適度放大，不再留下大片空白。
- **安裝版一鍵更新**：按一次「更新並重新開啟」即可接續下載、驗證、保存、安裝與重開；遊戲執行中會等關閉後自動繼續。

## 主要功能

- **戰績與戰局**：查詢亞服玩家戰績、近期變化、期間單艦戰績與目前戰局的 PR 評價，並複製戰績摘要。
- **RP 回放**：查看戰鬥事件、累積傷害、勳章與勳帶，支援暫停、跳轉與倒退。
- **戰鬥結算**：查看個人成績、隊伍成績、詳細報告與銀幣及經驗，依傷害、基本經驗、擊沉、擊落或單場 PR 排序玩家。
- **影片匯出**：將 RP 回放匯出為 720p／1080p、30 fps 的 H.264 MP4 影片，支援 1／2／4／8／16 倍速；匯出影片不含音訊。
- **艦艇分析**：查閱艦艇資料、比較配裝、檢視 3D 模型，以及比較散布與彈道。

## 安裝與更新

- **安裝版**：執行下載的 Setup，依畫面指示安裝。更新時會保留原安裝位置、設定與紀錄。
- **程式內更新**：本版起可使用「更新並重新開啟」完成後續更新。尚未支援一鍵更新的舊版，首次升級到本版仍需依原畫面完成下載與安裝；其他舊版請下載安裝版手動更新。
- **ZIP 版**：完整解壓縮後，開啟 `戰艦世界小幫手.exe`，並保留同資料夾內的其他檔案。更新前先關閉程式，手動更新程式檔時保留自己的完整 `data` 資料夾。
- 備份設定與紀錄時，先關閉程式，再複製程式資料夾內的完整 `data`。

## 使用提醒

- 適用於 **Windows 10／11 x64**，需支援 DirectX 12 的顯示環境。遊戲模型、貼圖與地圖等資源需從本機《戰艦世界》安裝讀取。
- RP 未記錄的資料會顯示「—」；銀幣與經驗的試算狀態依結算頁標示。
- 若影片功能提示缺少 Windows 媒體功能，請依程式提示安裝所需的媒體功能套件。

遇到問題時，請附上程式版本、操作步驟與錯誤畫面。設定頁提供診斷資訊與記錄資料夾入口，回報時不必提供完整 `data`。
