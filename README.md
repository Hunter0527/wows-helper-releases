# animal research projects

為《戰艦世界》玩家打造的 Windows 繁體中文工具，整合亞服戰績查詢、目前戰局資訊、RP 回放與影片匯出，以及艦艇資料與配裝分析。

## 主要功能

- **戰績與戰局**：查詢亞服玩家戰績、近期變化與目前戰局的 PR 評價，並複製戰績摘要。
- **RP 回放**：查看戰鬥事件、累積傷害、勳章與勳帶，支援暫停、跳轉與倒退。
- **戰鬥結算**：查看個人戰績、團隊成績、詳細報告與收益試算，依傷害、基本經驗、擊沉、擊落或單場 PR 排序玩家。
- **影片匯出**：將 RP 回放匯出為 720p／1080p、30 fps 的 H.264 MP4 影片，支援 1／2／4／8／16 倍速；匯出影片不含音訊。
- **艦艇分析**：查閱艦艇資料、比較配裝、檢視 3D 模型，以及比較散布與彈道。

## 安裝與更新

- **安裝版**：執行下載的 Setup，依畫面指示安裝。更新時會保留原安裝位置、設定與紀錄。
- **ZIP 版**：完整解壓縮後，開啟 `戰艦世界小幫手.exe`，並保留同資料夾內的其他檔案。更新前先關閉程式，更新程式檔時保留自己的完整 `data` 資料夾。
- 已有「檢查更新」功能的版本可從程式內更新；其他舊版請下載安裝版手動更新。
- 備份設定與紀錄時，先關閉程式，再複製程式資料夾內的完整 `data`。

## 使用提醒

- 適用於 **Windows 10／11 x64**，需支援 DirectX 12 的顯示環境。遊戲模型、貼圖與地圖等資源需從本機《戰艦世界》安裝讀取。
- 銀幣與經驗為**收益試算**；RP 未記錄的資料會顯示「—」。
- 若影片功能提示缺少 Windows 媒體功能，請依程式提示安裝所需的媒體功能套件。

遇到問題時，請附上程式版本、操作步驟與錯誤畫面。設定頁提供診斷資訊與記錄資料夾入口，回報時不必提供完整 `data`。
