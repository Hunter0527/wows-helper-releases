# animal research projects

Windows 繁體中文《戰艦世界》玩家工具，提供亞服戰績查詢、目前戰局水表、RP 戰績與回放，以及艦艇數據、模型、散布和彈道比較。

本儲存庫提供安裝檔、ZIP 免安裝版、版本說明及線上更新清單。**目前正式版為 V1.3（1.3.0）**，沿用通過審查的 V1.2.3-beta 功能，採用 animal research projects 名稱與憨猴抱船錨圖示。前往 [V1.3 下載頁](https://github.com/Hunter0527/wows-helper-releases/releases/tag/v1.3.0) 取得安裝版或 ZIP 免安裝版。

## 本版功能

- RP 回放依時間呈現累積傷害、勳章與勳帶，支援跳轉與倒退。
- 四頁戰鬥結算、玩家戰績排序，以及目前戰局的 PR 評價和摘要複製。
- 720p／1080p、30 fps、無音訊 H.264 MP4 匯出，支援多種播放倍速。
- 戰績查詢、近期變化、艦艇資料、配裝、3D 模型、散布與彈道比較。

## 下載與更新

- 安裝版：`animal-research-projects-v1.3.0-Windows-x64-Setup.exe`。更新沿用原安裝位置，保留設定及紀錄。
- ZIP 版：`animal-research-projects-v1.3.0-Windows-x64.zip`。更新時先關閉程式，再更新程式檔並保留自己的 `data`。
- 主程式檔名仍為 `戰艦世界小幫手.exe`，以維持既有更新相容性。請保留同層的 `wows-helper-updater.exe` 和 `wows-helper.ico`。
- V1.1 起支援程式內檢查更新。既有 V1.0.1 或較舊版本需先手動安裝一次包含更新功能的版本。
- 正式版與測試版使用不同更新通道；Alpha 測試環境獨立。

## 來源驗證

請從本儲存庫的 Releases 取得發布檔，並核對隨版本提供的 SHA-256。程式內更新會以內建公鑰驗證更新清單的 Ed25519 簽章，再檢查下載檔案的大小與 SHA-256。

更新清單有有效期限與發布序號；沒有可用版本時，清單中的 `release` 為 `null`。網路暫時不可用或更新清單到期時，現有程式功能仍可繼續使用。

## 資料保留與備份

個人設定、戰績快照、RP 索引與快取保存在程式資料夾的 `data`。安裝版更新保留這些資料；備份時先關閉程式，再複製完整 `data`。不要將自己的資料夾當作更新檔分享。

程式從使用者電腦上的《戰艦世界》安裝讀取遊戲資源。發布包不包含遊戲模型、貼圖、私人戰績紀錄或 RP。第三方元件授權隨發布包提供。

## 問題回報

請附上版本、操作步驟及錯誤畫面。程式設定頁提供診斷資訊與記錄資料夾入口，不必提供完整 `data`。銀幣與經驗頁維持「收益試算」標示。
