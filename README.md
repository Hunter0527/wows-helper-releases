# 戰艦世界小幫手

Windows 繁體中文《戰艦世界》玩家工具，提供亞服戰績查詢、目前戰局水表、RP 戰績與回放，以及艦艇數據、模型、散布和彈道比較。

本儲存庫專供安裝檔、ZIP 免安裝版、版本說明及線上更新清單使用。**目前已設置更新來源，尚未上架可下載版本。** 版本完成驗證後會出現在 [Releases](https://github.com/Hunter0527/wows-helper-releases/releases)。

## 下載與更新

- 安裝版使用 Windows x64 `Setup.exe`；後續更新沿用原安裝位置，保留設定及紀錄。
- ZIP 免安裝版解壓後使用。更新時先關閉程式，再更新程式檔並保留自己的 `data`。
- V1.1 起支援程式內檢查更新。既有 V1.0.1 或較舊版本需先手動安裝一次包含更新功能的版本。
- 正式版與預覽版使用不同更新通道；Alpha 測試環境獨立。

## 來源驗證

請從本儲存庫的 Releases 取得發布檔，並核對隨版本提供的 SHA-256。程式內更新會以內建公鑰驗證更新清單的 Ed25519 簽章，再檢查下載檔案的大小與 SHA-256。

更新清單有有效期限與發布序號；沒有可用版本時，清單中的 `release` 為 `null`。網路暫時不可用或更新清單到期時，現有程式功能仍可繼續使用。

## 資料保留與備份

個人設定、戰績快照、RP 索引與快取保存在小幫手資料夾的 `data`。安裝版更新保留這些資料；備份時先關閉小幫手，再複製完整 `data`。不要將自己的資料夾當作更新檔分享。

程式從使用者電腦上的《戰艦世界》安裝讀取遊戲資源。發布包不包含遊戲模型、貼圖、私人戰績紀錄或 RP。第三方元件授權隨發布包提供。

## 問題回報

請附上版本、操作步驟及錯誤畫面。程式設定頁提供診斷資訊與記錄資料夾入口，不必提供完整 `data`。

這是非官方玩家工具，與 Wargaming 無隸屬關係。
